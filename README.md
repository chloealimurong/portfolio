# Chloe Alimurong | Portfolio

Personal portfolio of Chloe Alimurong, a GIS and data analyst and Master of Urban Spatial Analytics student at the University of Pennsylvania. It collects my maps, research and projects in one place.

**Live site:** https://chloealimurong.github.io/portfolio

## What's on the site

- **About:** a short bio, my background in GIS and urban analytics, and links to GitHub and LinkedIn.
- **Projects:** my work in a grid, each with a short description and a link out. It includes:
  - the CTPN report *Protecting Soft Targets in an Age of Complex Threats* (2026), where I wrote the New Orleans, Las Vegas and Southport case studies
  - a literature review on social mix in East Asian countries such as Japan
  - Shanghai Virtual Lilong (co-authored)
  - a documentary film
- **Maps:** p5.js maps, including my [30 Day Map Challenge](https://chloealimurong.github.io/30DayMaps-2026/) entries and the Baltimore power price map.
- **Resume:** a link to my resume as a PDF.

## Built with

Plain HTML, CSS and JavaScript, with no static site generator. Maps use [p5.js](https://p5js.org/) and [d3](https://d3js.org/). Hosted on GitHub Pages.

## Project structure

## Inspiration and credits

- **Template:** this site started from the MUSA portfolio template for Penn students, which borrows styles from the [Urban Spatial Analytics](https://www.design.upenn.edu/urban-spatial-analytics) website at the Weitzman School of Design. I have since moved off Jekyll to plain HTML.
- **Original theme:** that template is based on the [Portfolio Jekyll Theme](https://github.com/LeNPaul/portfolio-jekyll-theme) by [Paul Le](http://lenpaul.com), released under the [MIT License](https://github.com/LeNPaul/portfolio-jekyll-theme/blob/gh-pages/LICENSE.md). Paul Le built it on the [DevTips Starter Kit](http://devtipsstarterkit.com/), following a [tutorial by Travis Neilson](https://www.youtube.com/watch?v=T6jKLsxbFg4&list=PL0CB3OvPhDA_STygmp3sDenx3UpdOMk7P).
- **Maps:** the circles and spirals draw on sketches by [Roni Kaufman](https://ronikaufman.github.io) on [OpenProcessing](https://openprocessing.org/@ronikaufman/2982301). The bokeh lights in the Baltimore power map are inspired by [this OpenProcessing sketch](https://openprocessing.org/@u180407/724534).
- **Icons:** [Font Awesome](http://fontawesome.io/), if you still use it.
